# ARNIS API - GUI VERSION
A script to automate big worlds using Arnis. Now With GUI !
 ## What is Arnis?
 You can find out all the great things about Arnis [here](https://arnismc.com/)!
❗ ( I am not a part of Arnis )❗

## Why not just use Arnis?
Arnis has limits, it fails to download the data if the area is to large. This app will keep going until done. *(or your computer crashes)*
## How to use?
Its really simple! 😊
1. This file is required: [Github Link](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson)
2. Download the app for your OS.
3. Run the app.
4. Edit the settings to your liking!
5. Then you just wait. A very, very, long time. 😟
